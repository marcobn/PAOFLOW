# Studio

PAOFLOW Studio (`paoflow-studio`) is the browser interface to PAOFLOW. It asks the questions of `paoflow-gen` as a form, writes the same files the command line writes, runs them and plots their outputs. It is one of three ways to run a case of `examples/cases`, next to `paoflow-gen --example <case>` and the Python API: *Examples…* in its Setup tab opens a case, and the [tutorials and how-tos](../learn/index.md) name the case they are built on.
