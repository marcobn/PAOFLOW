# Studies

One folder per system, e.g. `projects/NbSn2/`. Each holds:
- `analysis.py`, the analysis script;
- `data/`, the experimental inputs and canonical CSVs;
- the analysis outputs and reports.

Calculation folders stay where they are and are referenced by path.

Everything here except this README is ignored by git, so your studies never end up in a PAOFLOW commit. Keep them under your own version control if needed.
