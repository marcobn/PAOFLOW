# Studies

One folder per study, e.g. `projects/GaAs_SHG/`. Each holds `sources/`, `data/` (canonical datasets
with provenance and `model_curves.csv`), `checks/`, `tables/`, `figures/`, the scripts
`digitize_sources.py`, `analysis.py`, `plot_figures.py`, and `REPORT.md`. Calculation folders stay
where they are and are referenced by path, read-only. Everything here except this README is
ignored by git.
