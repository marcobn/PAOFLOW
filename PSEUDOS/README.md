# Pseudopotentials

This folder contains pseudopotential repositories from [Pseudo Dojo](https://www.pseudo-dojo.org/).

The provided sets are for **standard precision**, but any distribution from the Pseudo Dojo website can be used.

## Using other pseudopotential sets

If you download other versions (ultrasoft or higher precision), each pseudo folder must contain:

1. **`reference.json`** — the file with suggested energy cutoffs.
   Download it from the [Pseudo Dojo website repository](https://github.com/abinit/pseudo_dojo/tree/master/website).

2. **`PeriodicTableJSON.json`** — the periodic table data file.
   Copy it from [Bowserinator/Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON/blob/master/PeriodicTableJSON.json).
