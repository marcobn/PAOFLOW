# 07: Interject (a watcher event)

```
The watcher reported: <paste its output, or "read STATUS.md">. For each finding: verify the evidence from the files
(Campaign.status, the output, the log tail); then act within the authority of ACTIONS: `act` findings -> do it,
journal it with the evidence, report; `ask` findings -> propose options (fix, cost, what it changes in the results)
and wait; `report` findings -> report. Fix causes, not symptoms: before any resubmission show the cause in the output.
Restart the watcher when done.
```

**Check:** every action taken is in JOURNAL.md with its evidence and is an `act` of ACTIONS; everything else is a proposal.
