# 08: Report

**When:** metrics, diagnosis and figures are done.

```
Write REPORT.md from templates/report_template.md, written for <audience>: provenance caveat box (mu*, gap and Tc
definitions, temperatures, grids and smearing, code version, the inversion's assumptions), bottom-line table
(observable, agreement, discrepancy, likely cause), data inventory (source, method, definition, form, uncertainty),
model run (describe() of every adapter), results per comparison with numbers, baselines and files (the Tc table with
its mu* sensitivity), diagnosis and proposed runs, how to reproduce. Every number must come from tables/ or a named
file.
```

**Check:** spot-check five numbers in the report against tables/; the caveat box names every definition and parameter.
