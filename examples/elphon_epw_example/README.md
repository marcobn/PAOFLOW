# Pb electron–phonon (Eliashberg) — PAOFLOW on EPW's coarse coupling

This example computes the isotropic Eliashberg properties of fcc lead (α²F, λ,
ω_log, Tc) with PAOFLOW's PAO interpolation. The coarse coupling comes from
**EPW** (`epbwrite`). EPW evaluates both ψ_k and ψ_{k+q} from the nscf save, so
its matrix elements share the band gauge of PAOFLOW's projections on that save,
which the interpolation needs (see `docs/internals/Electron-Phonon-Coupling.md`).

EPW is run **without Wannier functions** (`wannierize = .false.`). It only
computes the coarse matrix elements; PAOFLOW does all the interpolation. The
physical setup is that of the EPW tutorial 04 (Pb superconductivity,
<https://docs.epw-code.org/tutorials/tutorial_04/index.html>): 6³ coarse k and q
grids, with ph.x on the 16 irreducible q only.

The directory is laid out exactly as `paoflow-gen` (electron-phonon workflow,
EPW source) produces it: a single folder and a single QE outdir.

---

## Directory contents

| file | purpose |
|------|---------|
| `scf.in` | `pw.x` scf (8³ k, with symmetry) |
| `nscf.in` | `pw.x` nscf on the full 6³ grid, explicit `K_POINTS crystal` list (`nbnd = 16`) |
| `main.elphon.py` | generated by `paoflow-gen`: `inputs` phase (QE/EPW inputs) and analysis |
| `plot.elphon.py` | generated by `paoflow-gen`: α²F and cumulative λ (overlays EPW's `pb.a2f` if present) |

`python main.elphon.py inputs` writes the remaining inputs:

| file | purpose |
|------|---------|
| `pb.ph.in` | `ph.x` DFPT on the 6³ q-grid (irreducible q, `fildvscf = 'dvscf'`) |
| `nscf.kpoints` | the explicit full k list, already appended to `nscf.in` here |
| `epw.in` | `epw.x` with `epbwrite = .true.`, `wannierize = .false.`, `exclude_bands = 1:5`, `dvscf_dir = './save'` |
| `pb.ukk` (+ `pb.bvec`, `pb.mmn`) | band bookkeeping EPW reads with `wannierize = .false.` (semicore 5d bands 1–5 excluded), and empty wannier90 stubs so `epw.x` finishes cleanly |

**Pseudopotential:** copy `Pb.upf` (ONCVPSP, from the EPW tutorial material) into
this directory (`pseudo_dir = './'`).

---

## Procedure

Everything runs in this directory, in this order:

```bash
mpirun -np 8 pw.x -in scf.in > scf.out
python main.elphon.py inputs                 # pb.ph.in, nscf.kpoints, epw.in, pb.ukk (+ stubs)
mpirun -np 8 ph.x -in pb.ph.in > ph.out
python3 /path/to/q-e/EPW/bin/pp.py           # prefix 'pb' -> save/ (dvscf, patterns, dyn)
mpirun -np 8 pw.x -in nscf.in > nscf.out     # full k list; overwrites pb.save
mpirun -np 8 epw.x -nk 8 -in epw.in > epw.out   # one process per pool (-np = -nk)

paoflow-genbasis-ps --pseudo Pb.upf --out BASIS_PS
mpirun -np 8 python main.elphon.py           # PAOFLOW: alpha^2F, lambda, Tc (about 2 min on 8 cores)
python plot.elphon.py
```

- **Order:** the nscf overwrites `pb.save` with the full-grid wavefunctions, so
  it must come after ph.x and `pp.py`. `save/` is not touched by the nscf. EPW
  and PAOFLOW then both read the nscf save.
- **`pp.py`:** `save/pb.phsave/patterns.1.xml` must exist after `pp.py`;
  otherwise `epw.x` stops with "cannot open file for reading or writing".
- **What PAOFLOW reads:** `epw.x` writes `pb.epb1 … pb.epbN` (the coarse Bloch
  coupling, one file per pool). Together with `pb.ukk` they are all PAOFLOW
  reads. After "The .epb files have been correctly written" EPW runs its Wannier
  stage on the empty stubs; that output is not used.
- **EPW cost:** the coarse coupling scales with the number of pools and the
  kept bands, so use as many pools as the k-points allow.
- **Tested with:** QE/EPW 7.5 (EPW 6.0).
- **ph.x mixing:** the generated `pb.ph.in` keeps ph.x defaults; the EPW
  tutorial adds `alpha_mix(1) = 0.1` for faster DFPT convergence, which does not
  change the result.

`main.elphon.py` uses the `standard` PAO configuration (5d 6s 6p plus 6d 7s 7p,
18 orbitals) and the dense grids k 48³ / q 24³ with σ = 0.05 eV (EPW's
`degaussw`). Edit the constants at the top to change them; set `DENSE_Q = False`
for the cheaper coarse-q workflow. Output: `output/alpha2F.dat` (ω in meV, α²F)
and `output/eliashberg.npz` (all result arrays).

## Reference results (Pb, μ* = 0.1, σ = 0.05 eV)

| | λ | ω_log | Tc McMillan | Tc Allen–Dynes |
|---|---|---|---|---|
| PAOFLOW, k 48³ / q 24³ (this example) | 1.221 | 4.50 meV | 4.77 K | 5.21 K |
| PAOFLOW, k 24³ / q 24³ | 1.066 | 5.19 meV | 4.61 K | 4.94 K |
| PAOFLOW, k 48³ / q 24³, on a Wannierized EPW run | 1.221 | 4.50 meV | 4.77 K | 5.21 K |
| EPW itself, k 48³ / q 24³ (Wannierized run) | 1.151 | 4.44 meV | 4.38 K | 4.76 K |
| EPW tutorial 04 | 1.158 | 4.40 meV | 4.37 K | 4.75 K |

The remaining difference from EPW follows the density of states at E_F of the
two band interpolations: 0.251 /eV/spin for the 18-orbital PAO bands against
0.235 for EPW's 4 Wannier functions. The coarse-q workflow (λ ≈ 1.6) is not
converged in q.

## Notes

- **Commensurate grids:** the coarse q-grid must divide the coarse k-grid (here
  6³ / 6³), and `NK_DENSE` must be a multiple of `NQ_DENSE`. `paoflow-gen`
  enforces both.
- **Explicit k list:** EPW requires the full grid as `K_POINTS crystal` in
  [0, 1). `nscf.kpoints` (from `PAOFLOW.gen.epw_inputs.kpoints_card`) is exactly
  the list in `nscf.in`. PAOFLOW recovers the grid from the list and runs
  `pao_hamiltonian(expand_wedge=False)`.
- **Band exclusion without Wannier functions:** with `wannierize = .false.`
  EPW takes the excluded bands from `pb.ukk`; `bands_skipped` in `epw.in` only
  records the choice.
- **Wannierized EPW runs** (as in the EPW tutorials) give the same `.epb`
  content and work too, as long as the outer disentanglement window contains
  every band (no `dis_win_min/max`).
- **Two folders** (EPW tutorial layout, `phonon/` and `epw/`) also work. In that
  case copy `charge-density.dat` and `data-file-schema.xml` from
  `phonon/pb.save` into `epw/pb.save` before the nscf, and set
  `dvscf_dir = '../phonon/save'`.
