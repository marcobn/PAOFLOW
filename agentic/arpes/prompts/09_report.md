# 09: Report

**When:** metrics, diagnosis and figures are done.

```
Write REPORT.md from templates/report_template.md, written for <audience>: provenance caveat box (bare-band protocol,
k_F and E_F alignments, resolution, impurity offset, colour-scale assumption), bottom-line table (observable, agreement,
discrepancy, likely cause), data inventory (source, conditions, form, method, uncertainty), model run (describe(), the
flags used), results per comparison with numbers, baselines and files (lambda by method), diagnosis and proposed runs,
how to reproduce. Every number must come from tables/ or a named file.
```

**Check:** spot-check five numbers in the report against tables/; the caveat box names every assumption and protocol.
