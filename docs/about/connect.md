# Connect

## Getting Help

For installation questions and release information, visit the [PAOFLOW PyPI project page](https://pypi.org/project/PAOFLOW/).

For community support, use [GitHub Discussions](https://github.com/marcobn/PAOFLOW/discussions):

- Questions about PAOFLOW usage
- Help with specific workflows or calculations
- General community discussions
- Best-practice recommendations

## Bug Reports and Feature Requests

Submit bug reports and feature requests as [GitHub Issues](https://github.com/marcobn/PAOFLOW/issues).

Before opening a new issue, search existing issues to avoid duplicates. Bug reports and feature requests both go through the same Issues tracker.

## Contributing

PAOFLOW follows a discussion-first contribution model to avoid duplicated work and conflicting implementations.

1. Identify an issue to work on.
2. Open or comment on a GitHub Issue describing your proposed solution.
3. Discuss the approach with the maintainers.
4. Wait for approval or feedback from the core developers.
5. Begin implementation only after agreement has been reached.
6. Submit a Pull Request referencing the approved issue.

Unapproved large contributions may not be accepted. Early discussion ensures your work aligns with the project roadmap and architecture.
