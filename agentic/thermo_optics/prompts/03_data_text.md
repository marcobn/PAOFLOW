# 03: Experimental numbers in free text

**When:** values quoted in a paper's text, notes, e-mails or slide text.

```
Transcribe every quantitative statement about <observable> from <source, pages/sections>: value, unit, condition
(T, sample, wavelength...), uncertainty if given, and the sentence (in `note`). Provenance 'transcribed'.
Write <study>/data/<source>_text.csv. Flag statements that are derived by the authors (fits, model-dependent inversions)
rather than measured, and say which model they assume.
```

**Check:** every row has its sentence; derived numbers are marked as such.
