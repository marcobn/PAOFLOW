# Contribute

PAOFLOW is an open project and contributions of all kinds are welcome — code, documentation, examples, bug reports, and feedback.

## Getting Started

The best first step is to browse the open [GitHub Issues](https://github.com/marcobn/PAOFLOW/issues) to find something that interests you, or open a new issue describing what you have in mind. We follow a **discussion-first** approach to make sure effort is well spent.

1. Find or open an issue for what you want to work on.
2. Comment with your intended approach and get feedback from maintainers.
3. Once the direction is agreed, start implementing.
4. Open a Pull Request referencing the issue when ready.

Starting with a conversation before diving into code helps avoid situations where a lot of work goes in a direction that doesn't fit the project roadmap.

## Reporting Issues

Found a bug or want to request a feature? Open a [GitHub Issue](https://github.com/marcobn/PAOFLOW/issues). A quick search of existing issues first can save time — someone may have already reported the same thing.

For general questions and community discussion, visit [GitHub Discussions](https://github.com/marcobn/PAOFLOW/discussions).
