# PAOFLOW EDTB API Documentation

API reference for the environment-dependent tight-binding (EDTB) modules in PAOFLOW.

## Modules

| Module | Description |
|--------|-------------|
| [sk_fitting](api/sk_fitting.md) | Slater-Koster parameter fitting |
| [models](api/models.md) | Tight-binding model definitions |
| [edtb_params](api/edtb_params.md) | EDTB parameter management |
| [surface_project](api/surface_project.md) | Projected bulk band structure onto surfaces |
| [dual_params](api/dual_params.md) | Dual parameter handling |
| [band_unfold](api/band_unfold.md) | Band unfolding from supercell to primitive BZ |
