# 11: Report

**When:** metrics, diagnosis and figures are done.

```
Write REPORT.md from templates/report_template.md, written for <audience>: provenance caveat box, bottom-line table
(observable, agreement, discrepancy, likely cause), data inventory (source, form, method, uncertainty, assumptions),
model run, results per comparison with numbers and files, diagnosis and proposed runs, how to reproduce. Every number
must come from tables/ or a named file.
```

**Check:** spot-check five numbers in the report against tables/; the caveat box names every assumption.
