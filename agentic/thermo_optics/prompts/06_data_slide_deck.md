# 06: Slide decks

**When:** experimental results come as a pptx (or a PDF of slides).

```
Run ingest.extract_slide_deck(<deck>, <study>/sources/deck) (or render the PDF pages) and show me slides.md.
Identify: tables in the slide text (-> prompt 02), statements (-> 03), figures (-> 04/05). Record which slide each
dataset comes from (locator) and every unit or condition the slides leave implicit, as questions for me.
```

**Check:** nothing on the slides is taken as raw data unless the presenter says so.
