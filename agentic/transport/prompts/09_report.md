# 09: Report

**When:** metrics, diagnosis and figures are done.

```
Write REPORT.md from templates/report_template.md, written for <audience>: provenance caveat box (including the
Hall factor, rho0, doping and temperature-window assumptions), bottom-line table (observable, agreement,
discrepancy, likely cause), data inventory (source, sample, form, method, uncertainty), model run (describe() of
every adapter, flags actually used), results per comparison with numbers, baselines and files, diagnosis and
proposed runs, how to reproduce. Every number must come from tables/ or a named file.
```

**Check:** spot-check five numbers in the report against tables/; the caveat box names every assumption and correction.
